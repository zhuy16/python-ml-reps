# v0.2.0 — Practice Buckets & Expanded Question Bank

**Released:** 2026-05-04

## Summary

Major expansion: the app now organises all questions into three focused **practice buckets** selectable from a radio button at the top of the UI. Total question count grows from 10 to **39**.

---

## New Features

### Practice Bucket System

- Added a **bucket radio selector** in the app header: `🔵 Basic (ML / Python)` · `🧬 Bioinformatics Engineer` · `🏥 Clinical DS`
- Each bucket maintains its own question pool, navigation, and difficulty tracking independently
- Switching buckets resets the current question and clears run output
- `active_bucket` added to Streamlit session state; `_active_questions()` helper filters the pool by the selected bucket

### 🧬 Bioinformatics Engineer Bucket (17 questions)

New question list `HELIX_QUESTIONS` targeting practical bioinformatics engineering interviews. Questions cover:

**Strings / Bioinformatics**
- Reverse Complement DNA
- Count k-mers
- Find Mutations (ref vs query)
- Parse FASTA Text
- Parse VCF Format (new in this version)
- Parse FASTQ Reads (new in this version)

**Hash Maps / Dicts**
- Count Variants by Gene
- Group Records by Sample ID
- Deduplicate Variant Records
- Top N Frequent Items

**Lists / Sorting**
- Sort Variants by VAF
- Filter Variants (depth, VAF, consequence)
- Merge Genomic Intervals
- BED Interval Operations (new in this version)

**Pandas/EDA**
- Pandas Variant Table Analysis (new in this version)

**Algorithms**
- Two Sum
- Longest Substring Without Repeating

> Questions removed from this version compared to draft: `group_anagrams`, `valid_parentheses`, `binary_search` — deprioritised in favour of practical genomics tasks.

### 🏥 Clinical DS Bucket (12 questions)

New question list `CLINICAL_QUESTIONS` targeting clinical data science roles. Requires `lifelines`.

**Pandas from Memory**
- Clinical DataFrame EDA
- GroupBy Clinical Outcomes
- Merge Patient Tables
- Derived Columns on Clinical Data

**scikit-learn**
- Logistic Regression: Fit → Predict → Report
- ROC Curve + AUC
- sklearn Pipeline
- Cross-Validation AUC

**Survival Analysis (lifelines)**
- Kaplan-Meier Curve (Basic)
- KM Curves by Treatment Arm
- Log-Rank Test
- Cox Proportional Hazards Model

---

## Changes to Existing Code

- `ALL_QUESTIONS` extended: `QUESTIONS + HELIX_QUESTIONS + CLINICAL_QUESTIONS`
- `CATEGORY_ICON` extended with `"Survival Analysis": "📈"`
- `_pool()` and `_current()` updated to operate on `_active_questions()` instead of the global `QUESTIONS`
- Header metrics now reflect counts within the active bucket only
- Topic overview grid scoped to the active bucket
- Miss tracker still references `ALL_QUESTIONS` for persistence across buckets

---

## Dependencies

- Added `lifelines` to `requirements.txt` (required for Clinical DS survival analysis questions)

---

## Bug Fixes

- Fixed `SyntaxError` in the `parse_fasta` prompt: unescaped triple-quote `"""` inside a triple-quoted string (escaped to `\"\"\"`)
- Fixed malformed `two_sum` / `longest_no_repeat` dict structure caused by an incomplete removal of `valid_parentheses`
