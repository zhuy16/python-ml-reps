# v0.3.0 — Learning UX Overhaul (2026-05-05)

## New features

### My Code ↔ Solution toggle
- Two toggle buttons (`📝 My Code` / `✅ Solution`) above the editor let you flip between your work-in-progress and the full solution without losing either.
- Your WIP is preserved in session state while browsing the solution and restored instantly on switch-back.
- The Ace editor remounts with the correct content when the mode changes.

### Ctrl+S / Cmd+S keyboard shortcut
- Press `Ctrl+S` (or `Cmd+S` on Mac) anywhere on the page — including inside the code editor — to toggle between My Code and Solution.
- Implemented via a `components.html` JS injection that attaches the listener to both the parent document and every iframe (including the Ace editor's sandboxed iframe), polling every 800 ms for newly mounted iframes after reruns.

### Always-on code diff
- `🔍 Diff: My Code vs Solution` expander is visible at all times below the editor (not gated behind Solution mode).
- Auto-expands by default; toggle `🧠 Hard mode (hide diff)` to collapse it and force genuine recall before peeking.
- Diff is normalised before comparison: trailing whitespace stripped, internal alignment spaces collapsed, and default boilerplate lines (`# <title>`, `# Write your solution here`) removed from the WIP side so formatting differences do not show as false changes.

### Per-question notes
- `📌 My Notes` text area in the right panel persists a personal insight/mnemonic for each question in session state.

### Spaced repetition weighting
- `🎲 Next Random` replaced uniform `random.choice` with weighted `random.choices`:
  - Unrated questions → weight 2
  - Hard questions → weight 4 + miss count
  - Easy questions → weight 1
- Weak spots naturally surface more often without any extra configuration.

### Progress bar
- A compact `st.progress` bar sits inline with the header metrics, showing `X/N mastered (%)` for the active bucket. Displays `🏆 Bucket complete!` when all questions are marked Easy.

## UI / layout improvements

- **Compact header**: replaced `st.title` + `st.metric` boxes with a single inline markdown row, cutting header height from ~150 px to ~30 px.
- **Column ratio**: `[2, 3, 2]` → `[2, 5, 1.5]` — centre workspace now takes ~59 % of page width.
- **Bucket selector**: removed redundant `[3, 7]` column wrapper; radio fills full width.
- **Left panel**: removed "Jump to a topic" dropdown and "🎲 Next Random" button (navigation is through the topic grid); moved `🗂️ Topics` grid to the bottom of the left panel with a smaller label.
- **Centre panel**: removed "💻 Your Workspace" heading, workspace tip info box, and "✏️ Code Editor" label — editor starts immediately.
- **Right panel**: removed "🔍 Show Solution" button (solution is now accessible via the editor toggle).
- **Top padding**: injected CSS `padding-top: 0.6rem` to eliminate the large default gap at the top of the page.

## Removed
- `st.title` / `st.caption` / `st.metric` from header (replaced with compact markdown)
- "Show Solution" / "Hide Solution" button from the right reference panel
- "Jump to a topic" label + selectbox from the left panel
- "🎲 Next Random" button from the left panel
- Workspace tip `st.info` box and section headings from the centre panel
