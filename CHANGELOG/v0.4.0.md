# v0.4.0 — Integrated Drills + Persistence + Execution Controls (2026-05-06)

## New features

### Integrated bucket
- Added a new `🧩 Integrated` practice bucket with a realistic end-to-end VCF pipeline drill.
- Exercise flow: parse VCF from file, preprocess missing values, run EDA, summarize with groupby, merge metadata, and generate distribution plots.
- Added sample dataset at `data/sample.vcf` with ~300 variant rows for realistic parsing and cleaning practice.

### Solution execution controls
- Added `🧪 Run Solution` button so solution code can be executed directly for verification.
- `▶ Run Code` / `🧪 Run Solution` now execute live editor state correctly when editing in Solution mode.
- Added keyboard shortcut `Shift+Enter` (alongside `Ctrl+Enter` / `Cmd+Enter`) to run code.

### Persistent progress and custom solutions
- Added autosave/load of progress to `.streamlit/practice_progress.json`.
- Persisted state includes per-question code, notes, editor mode, difficulty ratings, miss counts, and custom solution overrides.
- Added `⭐ Use My Code as Solution` (enabled only after successful execution of the exact current My Code content).
- Added `↩ Restore Original Solution` to revert promoted custom solutions.

## Stability and UX hardening

- Added guardrails for malformed custom solutions:
  - invalid custom solution code is detected and automatically replaced by the original built-in solution.
- Improved run-state tracking with per-question success status and last executed code snapshot.
- Updated integrated VCF examples to stream file input line-by-line (no `readlines()` full buffering).

## Tests

- Refactored VCF tests into reusable parse/clean helpers for easier maintenance.
- Added a second integrated-style pipeline validation test (groupby + merge checks).
- Test suite now validates expanded sample VCF behavior and continues to pass.
