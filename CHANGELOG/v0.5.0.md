# v0.5.0 — Layout Polish, Output Panel, Robustness

## New Features

### Layout Controls
- **Left panel width slider** (1.0–4.0) and **right panel width slider** (2.0–7.0) — adjustable alongside the existing editor height slider
- All three sliders are persisted across restarts
- Right panel now dynamically sizes to match the left and center, centre auto-fills remaining space
- All 4 hide/show combinations (left, right, both, neither) respect the new width settings

### Output Panel
- Run output (stdout, errors, matplotlib plots) moved to the **right panel**
- Output container height matches the editor height slider automatically
- Right panel top area shows Hard Questions Only toggle; output appears directly below
- Diff panel removed; right panel is now output-focused

### Button Row Reorganisation
- **Mark Easy / Mark Hard** moved into the center panel second row (alongside Use My Code as Solution, Restore Original)
- Buttons styled smaller via CSS (0.75 rem font, compact padding)
- Question title reduced to `####` heading size
- Show Hint and Reset Progress buttons removed from right panel

### Integrated Drills Bucket
- "Integrated Clinical Genomics Drill" moved from Clinical DS → **Integrated Drills** bucket
- Category updated to `Integrated Drill`

### Session Persistence
- **Active bucket** and **current question** now saved to `.streamlit/practice_progress.json`
- App restores the exact bucket and question from the last session on restart
- Safe validation: falls back to first question in bucket if saved ID is stale

## Bug Fixes

- **`SyntaxError: unterminated f-string literal`** — fixed recurring error when running solution/user code that had `print(f"...\n...")` split across lines by the Ace editor
  - Added `_repair_split_print_strings(code)` pre-processor applied before every `compile()` call
  - On `SyntaxError` with unterminated-string/f-string message, a second repair pass is attempted automatically
- **Run Solution** now always executes the canonical solution text (not the potentially corrupted live editor snapshot)
- **Keyboard shortcuts not firing** — rewrote shortcut JS injection:
  - Switched from `window.parent` to `window.top` to reach the real browser document through Streamlit's iframe layers
  - Replaced one-time `_shortcutBound` flag (blocked re-attachment after reruns) with a remove-then-add pattern (`_kbOnKey`) on every poll cycle
  - Added recursive iframe walk so nested iframes (e.g. Ace editor inside a component iframe) are covered
  - Also attaches to `window.parent` when it differs from `window.top`
