# v0.7.0 - LangChain / LangGraph Bucket

## Added
- New bucket: **LangChain / LangGraph** (`🦜`) with 8 practice questions:
  - Chat Prompt Template (LCEL chaining with `ChatAnthropic`)
  - Output Parsers (`StrOutputParser` + `with_structured_output`)
  - RAG — Embed & Retrieve (local `HuggingFaceEmbeddings` + FAISS)
  - RAG — Full QA Chain (LCEL RAG pattern with `RunnablePassthrough`)
  - LangGraph — Basic State Graph (`StateGraph`, `END`, node functions)
  - LangGraph — Conditional Routing (`add_conditional_edges`, router fn)
  - LangGraph — LLM Agent with Tools (`ToolNode`, `tools_condition`, `MessagesState`)
  - Conversational Memory (`RunnableWithMessageHistory`, `InMemoryChatMessageHistory`)
- New integrated drill in Integrated bucket:
  - **LangChain / LangGraph End-to-End Drill**: local embeddings → FAISS → `create_retriever_tool` + `@tool` → `ChatAnthropic.bind_tools` → `StateGraph` agent → `with_structured_output`
- Sidebar **API Keys** panel showing `ANTHROPIC_API_KEY` detection status.

## Changed
- All LangChain/LangGraph exercises use **`ChatAnthropic` (`claude-haiku-4-5`)** — no OpenAI key required.
- RAG exercises use **`HuggingFaceEmbeddings(model_name="all-MiniLM-L6-v2")`** (local, ~90 MB, no API key) instead of OpenAI embeddings.
- Added `import os` to top-level imports in `streamlit_app.py`.
- Updated `requirements.txt` with new dependencies.

## Fixed
- **SyntaxError in LangGraph exercises** — `@tool` docstrings were stored as `\\"\\"\\"...\\"\\"\\"` (escaped quotes) which rendered as `\"\"\"` when exec'd; replaced with `'''...'''` single-quoted docstrings across all 8 occurrences.
- **`ValidationError` in Output Parsers exercise** — `MLConcept.example` was a required field but Claude omitted it; made `example` optional with `default=""` and added explicit field instructions to the prompt.
- **Duplicate labels in Topics grid** — `_topic_label()` was splitting on `—` and showing only the prefix, making `"RAG — Embed & Retrieve"` and `"RAG — Full QA Chain"` both display as `"RAG"`. Now shows the full title (truncated at 30 chars).
- **Basic bucket icon** — replaced `🔵` with `⚡` to avoid confusion with the radio-button selection dot.
