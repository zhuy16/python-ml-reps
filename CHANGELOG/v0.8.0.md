# v0.8.0 - Practice UX + Efficiency + Unfamiliar Python

## Added
- New bucket: **Python Efficiency** (`🧵`) with 12 exercises focused on:
  - Dict/set lookup vs nested loops
  - Generator memory savings
  - List-comprehension filtering patterns
  - `ThreadPoolExecutor` and per-future exception handling
  - `map()` vs `as_completed()` behavior
  - Queueing behavior with `submit()`
  - Dict merge and key-set comparisons
  - Batch iterators for memory-safe loops
  - `ProcessPoolExecutor` for CPU-bound tasks
  - AnnData concat patterns and memory-aware `.h5ad` normalization workflows
- New bucket: **Unfamiliar Python** (`🧠`) with day-structured drills (13 exercises):
  - Day 1: concurrency fundamentals (threading, race conditions, locks, multiprocessing, asyncio)
  - Day 2: core language idioms (dunder methods, decorators, generators, context managers, type hints)
  - Day 3: pytest practice (parametrize, fixtures, mocking)
  - Day 4: timed code-reading and Big-O warmups
- New test coverage in [tests/test_python_boilerplate.py](../tests/test_python_boilerplate.py):
  - dict lookup vs nested loops
  - generator vs list memory behavior
  - list-comprehension filtering
  - thread-pool parallel processing
  - thread-pool exception handling

## Changed
- **Ask Claude** now includes the active question solution code as context for general Q&A, improving explanation quality.
- Added explicit question/error prompting mode in LLM helper flow so error explanations and general tutoring prompts are handled separately.
- Bucket selector now includes **Unfamiliar Python**, and all bucket validation/restore logic supports it.

## UI/UX
- Added **Split solution** side-by-side learning mode:
  - Reference solution shown in a left panel
  - Editor remains on the right for copy-by-typing workflows
  - Adjustable split width control
- Moved **Ask Claude** panel higher in the right column for faster access.
- Added per-question run-source highlighting so **Run Code** and **Run Solution** clearly reflect the last executed source.

## Fixed
- Fixed run-button primary-state bug where **Run Code** appeared primary/red regardless of which source was last executed.
- Fixed syntax issue introduced by embedded triple-quoted strings in a newly added practice solution block.

## Notes
- This release emphasizes practical fluency in Python concurrency and unfamiliar language patterns, while preserving the active-recall workflow.
